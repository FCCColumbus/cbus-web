freeCodeCamp certification list

(updated June 2024)

freeCodeCamp's core curriculum certifications

  • Responsive Web Design Certification

    • About: building using HTML and CSS. needed in all web and mobile applications
    • Prereq: nothing. build things right in your browser. Good entry point

  • JavaScript Algorithms and Data Structures (Beta) Certification

    • About: JavaScript is a powerful language which allows you to build websites that are interactive.
    • Prereq: For all of the projects in this curriculum, you will need to have a basic level knowledge of HTML and CSS. If you are new to HTML and CSS, please go through the Responsive Web Design Certification first.

  • Front End Development Libraries Certification

    • Prereq: HTML, CSS, JS
    • About: Bootstrap, jQuery, SASS, React...
    • Comments: if you like front end, then continue. Otherwise, maybe try something else

  • Data Visualization Certification

    • About: Data is all around us, but it doesn't mean much without shape or context. You build charts, graphs, and maps to present different types of data. Also learn JSON
    • Prereq: HTML, CSS, JS, and the JavaScript Algorithms and Data Structures are helpful but not necessarily required.
    • Comments: can be a little confusing because the full code is not there (eg: ref to D3 lib). The online lib for D3 shows some fulll examples of vanilla HTML

  • Relational Database Certification

    • About: use real developer tools and software including VS Code, PostgreSQL, and the Linux / Unix command line to complete interactive tutorials and build projects
    • Prereq: a decent machine with linux. Basic command line BASH commands will be used. you will also create a github account

  • Back End Development and APIs Certification

    • About: build applications is through microservices
    • Prereq: learn the basics of node.js (install and play with it), including the package manager npm (learn about packages as well). command line and a github account will also be needed

  • Quality Assurance Certification

    • About: learn how to write tests with Chai (JS framework). This is for automated unit testing
    • Prereq: HTML, CSS, JS, github

  • Scientific Computing with Python (Beta) Certification

    • About: analyze and manipulate data using Python. Learn key concepts like data structures, algorithm, Object Oriented Programming. the interpreter is online, so no installation needed
    • Prereq: not much. Good entry point
    • Comments: might be a REALLY GOOD Starting point to answer the question "do I want to be a developer"??

  • Data Analysis with Python Certification

    • About: learn about data analysis, and how to use open source tools to show really cool data elements (like Tableau, but free!)
    • Prereqs: a decent machine, and maybe openoffice (Calc, for example)

  • Information Security Certification

    • About: fundamentals of protecting people's information online.
    • Prereqs: HTML, CSS, JS cert (for some of the conceptual stuff), and GitHub, and a decent machine

  • Machine Learning with Python Certification

    • About: build several neural networks and explore more advanced techniques like natural language processing and reinforcement learning. Good entry point for AI
    • Prereq: one of the algorithm certs (like JavaScript Algorithms and Data Structure)

  • College Algebra with Python Certification

    • About: learn college algebra. Possibly for basic math skills and another good entry point for general coding and math skills needed in many logical jobs like SW dev
    • Prereq: a decent machine, some Python, and github

general notes about the curriculum

  • each certification has a set of courses that you must complete
  • you will see a preview of what you will build before you start
  • each course has a list of challenges you must complete. Each challenge builds on the previous challenge
  • Every challenge is guided, and the goal of each to get automated tests to pass
  • each course also has a Certification Project. Completing the certification project will earn you the certification
  • you need to create a free account and sign in to track your progress
